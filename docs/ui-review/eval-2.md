## P1

### 1. 会员详情页侧栏「会员」不亮

- 页面：`/members/:id`（所有角色）。
- 问题：侧栏用的是 `router-link-exact-active`，进了详情页侧栏一项都不亮，`aria-current` 也没有，不知道自己在哪个模块下。
- 建议：侧栏按路由的 `meta.page` 判断当前项，详情页算「会员」。

### 2. 财务：日期区间填错时，标题和数字对不上

- 页面：`/finance`。截图 `before/eval2-p1a/finance-range.png`。
- 问题：「从」改成晚于「到」，标题马上变成「2026.10.30 到 2026.10.23」，下面的数字还是上一次的区间；错误文案是普通黑字，夹在工具栏里不显眼。
- 建议：标题显示已经加载的数据的区间；区间不对时数字区变灰并标 `aria-busy`，错误文案用和其他页一样的提示块样式。

### 3. 前台看板「本月营收」显示一条大横线

- 页面：`/`（前台）。截图 `before/eval2-p1a/desk-dashboard.png`。
- 问题：接口不给前台营收，hero 卡片显示一个 64px 的「—」和「本月 1 日到今天」，像是数据坏了。
- 建议：没有营收字段时不显示这张卡，剩下三张铺满。

### 4. 「活动」占位页对员工讲开发的话

- 页面：`/events`（所有角色），`TodoPage.vue`。
- 问题：「设计稿在 prototype/ 原型的『管理后台』里」——员工不知道 prototype/ 是什么。
- 建议：改成「活动报名和签到还在做，做好之前请先线下登记。」。导航里要不要先藏掉见「待拍板」。

### 5. 前台平板页：前台账号进来是死路，后台也没有入口

- 页面：`/desk`。截图见第一轮 sweep（没进仓库）。
- 问题：前台账号打开只有一句「只有店长以上能绑定前台平板。」，没有回后台、换账号的按钮；后台各页也没有链接到 `/desk`，店长只能手输地址。
- 建议：前台账号时给「回后台」和「换个账号登录」；侧栏底部给店长以上加「前台平板」链接。

### 6. 表格行的键盘焦点几乎看不出来

- 页面：所有可点的表格（会员、员工、入场、卡种……），`ui-web/DataTable.vue`。
- 问题：Tab 到行上只有浅绿底（和鼠标悬停一样），`outline: none`；连续 Tab 时分不清焦点在哪一行。
- 建议：`tr.clickable:focus-visible` 加 3px 内描边（ink），悬停仍是浅绿底。

### 7. 浅色底上的灰字对比度不够

- 页面：入场页保险条、会员页「N 天没来」、错误提示块、表格悬停行。
- 问题：`--ink-muted #6e6e66` 在 `--brand-soft`、`--accent-soft`、`--neutral-soft` 上只有 4.32–4.33:1，12–13px 小字低于 4.5:1。
- 建议：这些浅色底容器里的说明文字改用 `--ink`（或 85% ink），不动全局主题色（主题和小程序共用）。

### 8. 会员不存在 / 加载失败只有一行灰字

- 页面：`/members/<不存在的 id>`。
- 问题：标题「会员详情」下面一行 13px 灰字，没有下一步；加载失败时也没有重试。
- 建议：用和其它页一样的提示块，给「回会员列表」，接口出错（不是 404）时给「重试」。

## P2

### 9. 复选框、单选框是浏览器默认蓝色

- 页面：设置、团课规则、卡种表单「在售」、登记入场选卡。
- 建议：`forms.css` 里 `accent-color: var(--brand-strong)`（原型是 olive-700）。

### 10. 窄屏表格横滑没有提示，操作列看不到

- 页面：390 宽的卡种（下架）、员工（停用）、入场（撤销）、课程（停用）。
- 问题：表格在卡片里横滑，右边被切掉的那一列正好是操作，没有任何提示能往右滑。
- 建议：DataTable 可横滑时右边缘加渐隐阴影，滑到底后消失。

### 11. 课程页私教日期在手机宽度折成四行

- 页面：`/courses` 390 宽。
- 建议：日期 chips 一行横滑，不折行。

### 12. 手机号列右对齐

- 页面：会员、员工、课程名单。
- 问题：手机号按数字列右对齐，但它是编号不是数量，左对齐更好读，也和原型一致。
- 建议：手机号列去掉 `num`，保留等宽数字。

### 13. 会员详情卡片上的「看流水 →」和「调整」两种样式

- 页面：`/members/:id` 卡片。
- 建议：都用 UiButton link 样式，放同一行。

### 14. 设置页冻结天数输入框占满整行

- 页面：`/settings`。
- 问题：上面两项是 120px，下面两项 476px，同一张卡里宽度不一致。
- 建议：数字输入统一 120px。

### 15. 「← 返回」太小太淡

- 页面：会员详情。13px 灰字，点击区 16px 高。
- 建议：14px ink、上下留出 32px 点击高度。

### 16. Tabs 不支持方向键

- 页面：入场与分享、所有 `role=tablist`。
- 问题：用了 `role=tab` 但没有左右方向键切换、没有 roving tabindex，读屏用户按 ARIA 习惯操作不了。
- 建议：左右 / Home / End 切换，未选中的 `tabindex=-1`。

### 17. 填错的输入框没有视觉标记

- 页面：所有 Field。
- 问题：报错时只在下面出提示块，输入框本身没变化（`aria-invalid` 有）。
- 建议：`[aria-invalid='true']` 用 accent-soft 底。

### 18. 团课规则加载完之前可以编辑和保存

- 页面：`/courses` 团课规则卡。
- 问题：规则接口还没回来时表单是空的、可以点保存，会报一堆「必填」；加载失败后也能保存空表。
- 建议：没加载成功前 fieldset 禁用，失败时给重试。

### 19. 财务「本月 / 上月 / 近 30 天」的「今天」在页面打开时就定死了

- 页面：`/finance`。
- 问题：`today` 在模块加载时算一次，过了零点不刷新的话「本月」还是昨天的区间（月初那天最明显）。
- 建议：点预设时再取今天。

### 20. 看板「7 天内到期」整行只有名字能点

- 页面：`/`。
- 问题：一整行 58px 高，只有名字那几个字是链接，右边的「N 天后到期」点了没反应。
- 建议：整行是一个链接（保留名字下划线），悬停整行变色。

## 待拍板

1. **「活动」页没做完，导航里要不要先藏起来？** 现在三个角色都能点进去看到「还在做」。藏起来更干净，但客户演示时可能想看到这一项。
2. **前台能不能看看板上的「新客从哪来」「老带新转化」？** 现在前台能看（营收已经藏了）。这是经营数据，馆长可能不想让前台看到。
3. **前台看别的店的会员时，归属门店显示「其他门店」。** 接口只给前台本店的名字。前台帮别店会员登记入场时，要不要能看到是哪家店（只读门店名）？
4. **「7 天内到期」要不要「提醒续费」按钮？** 原型有，但要定提醒方式（小程序订阅消息 / 短信 / 前台打电话记一笔），接口也还没有。
5. **看板缺的图要不要做？** 要么引入图表库，要么手写 SVG；第一轮说过先不引入图表库。
6. **前台平板入口放哪？** 第 5 条我先放在侧栏底部，只给店长以上；如果想放到设置页或者干脆不放（只发链接），改起来很小。
